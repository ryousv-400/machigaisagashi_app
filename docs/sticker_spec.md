# シール帳 画像生成 仕様書

**5歳児向けのかわいいシール 30種 + カプセル演出画像 1種を Codex で生成してもらう依頼書**

アプリでは、ステージをクリアするたびに 30 種類のシールから 1 枚がランダムに出現する「シール帳」機能を作ります。ぼんぼんどろっぷ（サンリオ系ぷくぷくシール）のような、**丸っこくてパステル、ふくらみのある絵柄**で統一してください。

---

## 共通スペック

- **解像度**: 1024 × 1024 px（正方形）
- **フォーマット**: PNG 透過（背景アルファなし＝完全透過）
- **配置**: シール本体は中央に配置し、**上下左右 8% 以上の余白**を確保（アプリ側で縁が切れないように）
- **画風統一**: 太めの白い縁取り（ステッカー風）＋ 柔らかな内側シャドウで「ぷくっと膨らんでいる」感じを出す
- **色**: パステル基調。ビビッドすぎず、黒はほぼ使わない（あっても超ダーク紺まで）
- **ファイル名**: `sticker_<slug>.png`（例: `sticker_bunny.png`）
- **保存先**: `public/kids/stickers/` ディレクトリ
- **キラキラ版は画像として用意しない**: アプリ側で CSS 演出（虹色グロー＋スパークル）を重ねるので、素材は 1 種類だけで OK

## 🎨 キャラクター方針

- 目はくりっと大きな丸、白ハイライト付き
- 口はニコッとした小さなカーブ（歯は見せない）
- ほっぺはピンクの小さな丸（任意）
- 動きを感じる構図（まっすぐ正面より、少し首かしげ・手を上げる等）
- 「怖い」「悲しい」表情は避ける。全部ハッピー or ふんわり

## 演出用画像（1種）

シールが出てくるガチャ演出でカプセルを開くアニメーションを使います。

- `capsule.png` — くるくる回る **カプセル（ガチャガシャの玉っぽいもの）**
  - 半透明のパステル色（ピンク〜ラベンダーのグラデ）
  - 中央に「？」マーク or きらめき
  - 1024×1024 透過PNG、`public/kids/` 直下

## 完成後の確認

1. `public/kids/stickers/` に 30 ファイルが揃っているか
2. ファイル名が仕様書通りの slug か
3. 透過背景になっているか（背景白にならないように）
4. 余白が十分か（アプリ側で回転・拡大演出するので、ギリギリだと見切れる）

完成したら「シール30枚できたよ」と伝えてください。アプリ側は画像なしでも動作するよう仮表示（絵文字フォールバック）で先に実装しているので、画像が届き次第自動で切り替わります。
