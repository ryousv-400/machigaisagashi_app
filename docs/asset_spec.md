# アセット仕様書（Codex 生成用）

このドキュメントは **5歳児向けまちがいさがしアプリ**の全ビジュアルアセットを
Codex（別のAIエージェント）に生成してもらうための仕様書です。

---

## 0. 全体の共通トーン

- **画風**: 明るいパステルカラーの絵本イラスト。太い輪郭線、丸みのあるフォルム。  
  参考イメージ: 「こどもちゃれんじ」「いないいないばあっ！」「ペネロペ」系。
  ピクサー／ジブリ風の陰影リッチは避ける。フラット寄り＋軽いシェーディング。
- **背景**: 単色 or 薄いグラデーション。主役が埋もれない構図。
- **主役**: 画面中央付近に大きく配置。ごちゃごちゃさせない。
- **色数**: 明るく飽和度高めのパステル（ピンク #ffb3d1 / 水色 #8fd3ff / クリーム #fff7e0 / ミント #d4f4e0 等）。
- **線**: 黒もしくはダークブラウン（#4a3f55 前後）の太線。
- **NG**: 写実表現、ホラー要素、武器、暴力、恐怖の表情。

## 1. ステージ画像（30 ペア × 各2枚 = 60枚）

### ファイル命名規則

```
public/stages/stage{NN}_left.png    # おてほん（完成版）
public/stages/stage{NN}_right.png   # もんだい（左から3箇所だけ変えたもの）
```

`NN` は 01〜30 のゼロパディング2桁。

### 画像サイズ

- **1024 × 1024 px（正方形 1:1）**
- PNG、アルファチャンネル不要（背景ベタでOK）
- ファイルサイズは 800KB 以下を目安（読み込み速度のため）

### 差分ルール（最重要！）

各 `left.png` と `right.png` の間には **必ず 3 箇所の差分** を入れる。

| 差分種類 | 説明 | 例 |
|---|---|---|
| A. 有無 | 片方には何かがある、片方にはない | 右にはリボンがあるが、左にはない |
| B. 色違い | 補色レベルではっきり違う色に | 赤いりんご ↔ 青いりんご |
| C. サイズ違い | 2倍以上の大きさ差 | 大きな雲 ↔ 小さな雲 |

**3箇所の内訳は「A×1 + B×1 + C×1」を推奨**（バランス良く楽しい）。

### 配置ルール

- 各差分は画像全体の **12% 四方以上** の大きさ（1024px なら約 123px 以上）
- 画面端（上下左右から 8% 以内）には配置しない
- 差分同士は **20% 以上離す**
- 左右で動かない共通要素（背景・主役キャラ等）はピクセル単位で揃える
- 差分の中心座標を記述する（後述の差分メモ欄に）

### 避けるべき差分

- ❌ 向きの違い（右向き ↔ 左向き）
- ❌ 位置のズレ（数ピクセルずれてるだけ）
- ❌ 細かい模様の違い（スパンコールの数など）
- ❌ 影の濃さや光源の違い
- ❌ グラデーションの微変化

## 1B. リアル差分版（むずかしいモード専用ステージ）

通常ステージ（30種）は5歳児入門用で、差分が大きく分かりやすい設計。
これとは別に、**もう少し腰を据えて取り組みたい子向け** に、絵本らしい
ふつうのまちがいさがしブックに近い「リアル差分版」のステージを追加する。

### 配置先・ファイル命名

```
public/kids/subtle/stage{NN}_left.png
public/kids/subtle/stage{NN}_right.png
public/kids/subtle/stages.generated.json   # メタデータ（差分座標）
```

`NN` は 01〜10 のゼロパディング2桁。まずは 1〜3 ステージで試作し、
合格ラインに達したら 10 ステージまで展開する。

### 画風（ユーザー提示の参考画像準拠）

- **やわらかい水彩タッチの絵本イラスト**
- 緑のもり、川、きのこ、小動物、花、結晶、木の洞 など
  「賑やかだが整理された絵本シーン」
- 主役（うさぎ、くま、こぎつね、ことり等）が **複数同居** していて、
  画面のあちこちに小さなディテールが散らばっている
- 色数は 8〜12 色程度。彩度は中庸（パステル + やや渋め）。
- 背景に薄い光の差し込みや、淡い葉の重なり。
- 「こどもちゃれんじ」より少しお姉さん向け、絵本『ノンタン』『パンどろぼう』
  寄りの密度感

### 差分ルール（リアル差分版）

通常版とは別ルール。**差分は3〜5箇所**（1ステージあたり可変）。

| 差分タイプ | 説明 | 例 |
|---|---|---|
| ① 小物の有無 | シーンに溶け込む小物が片方にだけある | きのこが1本増/減、花が1輪増/減 |
| ② 色のトーン違い | はっきりした補色ではなく **明度・彩度の微変化** | 葉の色が少し赤み寄り、屋根が少し暗い |
| ③ 数違い | 同じ要素の数が 1〜2 個違う | 小鳥が 3羽 → 2羽、星が 5つ → 4つ |
| ④ 微小な位置ズレ | 既存要素が **画像幅の 5〜10% 程度** ずれる | 蝶が少し右、看板が少し下 |
| ⑤ 形状の微変化 | 同じものが少し違う形 | 雲の輪郭、葉の形、しっぽの曲がり方 |

通常版で禁止していた「向き違い」「微妙な位置ズレ」「細かい模様違い」**は逆にここでは推奨**。
ただし「影の濃さ」「グラデの微変化」などプレイヤーが偶然タップで当てられない
ような曖昧な差分は依然 NG。

### ホットスポット（タップ判定）

- **画像全体の 6% 四方以上**（5歳児の指でタップ可能な最低サイズ）
- **見た目の差分は小さくても OK** だが、**タップ判定（メタデータの w/h）は
  指で押せる範囲に広げる**（差分の周辺 6〜10% を含むように）
- 互いに 12% 以上離す（通常版より緩い）
- 画面端 5% 以内は避ける

### 左右画像の生成手順（重要）

AI は同じプロンプトでも毎回違う絵を出すため、**左右で背景や主役の形が
微妙に違ってしまうと、まちがい探しとして成立しない**。
そこで以下の手順で生成する:

1. **ベース画像 1枚を生成** — 高解像度で気に入るものができるまで作る
2. **これを `_left.png` として確定**
3. 各差分について **マスク画像を作成** — 変更したい領域を白、それ以外を黒
4. **OpenAI `images.edit` API（gpt-image-1）** にベース画像 + マスク + 差分プロンプトを渡し、
   その領域だけ書き換えた画像を取得
5. **3〜5箇所すべての差分を順に edit で重ねる** → 完成版を `_right.png` として保存
6. ピクセル比較で「差分以外が完全一致しているか」を確認

> **NG**: 同じプロンプトを 2 回流して左右を作る方法は、AI 出力の揺らぎで
> 差分以外の要素も毎回変わるため絶対に使わない。必ず inpainting (edit API) を使う。

### 検証

座標自動抽出スクリプト（`scripts/find_diffs.mjs`）でリアル差分版を
処理した時、以下を満たすこと:

- [ ] 各ペアで「差分」と判定されるピクセルが **3 〜 5 クラスタ** に収まる
- [ ] それ以外の領域はピクセル一致（許容差 ±2 階調まで）
- [ ] 各クラスタが画像全体の 6% 四方以上に展開できる

## 3. マスコットキャラクター

アプリ全体に登場する主役キャラクター。今は絵文字 🐰 で代用中。

### ファイル

```
public/mascot/idle.png     # ふつう（待機）
public/mascot/happy.png    # よろこび（正解時）
public/mascot/sad.png      # しょんぼり（お手つき時）
public/mascot/hint.png     # 考え中（ヒント提供時）
```

### サイズ・フォーマット

- **512 × 512 px**
- **PNG、透過あり**（アルファチャンネル必要）
- 中央にキャラ、上下左右に 10% 程度の余白

### デザイン指針

- ステージ画像と同じ画風（パステル・太輪郭・丸み）で統一感
- **5歳児がすぐ好きになる** 親しみやすいデザイン
- 推奨モチーフ: うさぎ / くま / ねこ / ちいさな妖精 / 星の子 など（Codex 側で1つ選定）
- 丸っこく、目が大きめ、つむじ風のアクセント1つ
- 背景透過（PNG 透過）、影は落とさない（CSS 側で drop-shadow を掛ける）

### 4表情の違い

- **idle**: 穏やかな笑顔、ぱっちり目
- **happy**: 満面の笑顔、目を細めて嬉しそう、両手上げ or 飛び跳ね
- **sad**: しょんぼり、目を伏せる、涙はNG（悲しすぎる）、困った表情
- **hint**: 顎に手を当てて考えるポーズ、人差し指を立てるでも可
